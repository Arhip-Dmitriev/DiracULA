DIRACULA DOCUMENTATION
======================

Index and Conventions

Applies to: DiracULA 0.1.x (main branch, October 2026)
License:    Apache License 2.0


1. PURPOSE OF THIS DOCUMENTATION SET
------------------------------------

This directory is the reference documentation of DiracULA, the Dirac Universal Language for
Algorithm: a language for developing quantum algorithms without fixing the number of qudits or
their dimension. The documents specify the behaviour of the software as implemented: the
language, the command-line shell, the Python embedding, the ZX view of states and the Lean 4
certificates of results.

Where a document states a rule ("must", "never", "always"), that rule is enforced by the code.
Where behaviour is a current limitation rather than a design rule, the document says so
explicitly.

4. TYPOGRAPHICAL CONVENTIONS
----------------------------

  - Text to be typed literally, names of functions, files and values are written as they
    appear in the source, without quotation, or between double quotes when ambiguous.
  - In grammar summaries, square brackets [ ] enclose optional parts, a vertical bar |
    separates alternatives, and an ellipsis ... marks repetition. Upper-case words (NAME,
    EXPRESSION, STYLE) are placeholders.
  - Dirac notation is written in ASCII where the input syntax is meant (|0>^@n) and in Unicode
    where output is quoted (|0⟩^⊗n).
  - "d" denotes a qudit dimension, "n" a count of qudits, unless a section says otherwise.
    Both may be symbols.
  - Module paths are written in dotted form, e.g. diracula.pathsum.


5. NOTATIONAL CONVENTIONS OF THE MATHEMATICS
--------------------------------------------

  - omega_d = e^(2*pi*i/d), the principal d-th root of unity.
  - [P] is 1 when the proposition P holds and 0 otherwise (Iverson bracket).
  - A register of width w and dimension d holds a value in 0 .. d^w - 1, read big-endian in
    base d.
