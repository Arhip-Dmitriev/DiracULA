DIRACULA DOCUMENTATION
======================

Lean 4 Certificates of Language Results

Applies to: DiracULA 0.1.x
Lean library: diracula/lean (DiracULA: LSym, LDigit, LTable, LCanon, LPass, Lang; Lean 4.35.0)
Requires: Mathlib
Exporter: diracula.lean_lang (with its mirror diracula.lean_lsym)


1. PURPOSE
----------

A result a program prints can be certified: the certify statement and the --certify option
write a Lean 4 file stating and proving that the value the program computes, built from its
syntax, equals the printed closed form for every value of its size symbols. A certificate
that Lean accepts is correct relative to Lean, Mathlib, the definitions of the two Lean
libraries, and the translation of the program's syntax, which is shown in the file.

The proof goes through a verified normaliser of symbolic sums, never through ZX diagrams.


2. SETTING UP
-------------

See INSTALL.txt, section 3. In brief, from the library directory diracula/lean:

    lake exe cache get
    lake build
    lake env lean /path/to/certificate.lean

The library DiracULA depends on Mathlib only. Base, Sym, SymNorm and SymCanon define symbolic
sums and their verified normaliser (section 6.1); LSym, LDigit, LTable and LCanon extend them
with integer atoms; LPass rewrites atoms under facts about free variables (section 6.3); Lang
gives programs their meaning. In the shell,
--certify DIR writes certificates and --check checks each with Lean (SHELL.txt, section 3.5).



3. WHAT IS PROVED
-----------------

The certify statement and the --certify option (LANGUAGE.txt, section 14.3; SHELL.txt,
section 3.5) write one Lean file per result of a .ula program. Its main theorem has the form

    theorem SCRIPT_NAME (V : LV) (hρ : V.ρ.OK) HYPOTHESES :
        P.sem V = fun ν => axDen V ν R

P is the program as a Prog, R the printed value as an expression. V gives the values of the
dimension symbols (V.ρ.dv), the coefficient atoms and the functions a program calls
(V.fa); ν gives every index variable: output register i is ν i, input register i of a gate
is ν (IN + i), each parameter of the program (a var symbol) is ν (2000 + k). The theorem
holds for every V and every ν, so for every value of the symbols. Its hypotheses state the
range facts used: 2 ≤ d for each dimension, n : ℕ with ρ.dv k = d ^ n for each register of
d^n levels (d ^ (n + c) for the least offset c of the program, every other power of d written
over it), 1 ≤ n where the result needs it, and one hypothesis per assume statement.
V.ρ.OK states that every dimension is positive, every coefficient atom is nonzero and the
atoms come in conjugate pairs (atom 2j + 1 is the conjugate of atom 2j), so that a result
with complex parameters holds for every nonzero value of them. An integer parameter that only
multiplies amplitudes is read as a coefficient atom in the same way; a result that needs it real
has the hypothesis starRingEnd ℂ (V.ρ.atom 2k) = V.ρ.atom 2k for each such parameter, under which
the exponent of its conjugate atom is moved onto it (realT, certify_real_c).

A result whose proof reads a loop count as a width holds at every ν with ν (2000 + k) = n for
each such count: the parameter k the loop runs over equals the width n of the registers of
d^n levels. An assume statement D2 % D1 == 0 between dimension monomials is used as D1 ∣ D2.

A result of a program containing a loop over a symbolic range holds at every ν for which
the loop counts are nonnegative. An assertion A == B is proved as A.sem V = B.sem V. A
measured distribution is proved as one theorem per branch (the branch's probability is
|<value|psi>|^2), one that the probabilities sum to 1, one that <psi|psi> = 1 and, for a
function of the outcomes or an expression of measured values, one that every outcome maps
to a printed value of its probability and that the printed values are distinct, over ℕ for
integer values and over ℚ for rational ones. The density matrix a measurement leaves is
proved in its vectorised form, [o = o'] psi(o) conj(psi(o')).

normalise(s), shown or inside a larger expression, is proved as

    ∀ ν, axDen V ν R = ((Real.sqrt (⟨s|s⟩.sem V ν).re : ℝ) : ℂ)⁻¹ * s.sem V ν

from three facts: k s equals R, k² ⟨s|s⟩ = 1 and k is a positive real (nrm_cert), the first
two by the normaliser. An operator printed as the image of a basis ket, |x> -> E(x), is proved
as the operator applied to |x> for a free x equalling E(x). An operator equality that holds only
for reduced inputs is proved at every ν whose output and input variables lie in their ranges,
RgOK V RG ν (certify_rg, certify_eq_rg); each such variable v is read through a new atom mod(v, D),
which equals v there.

4. THE MEANING OF A PROGRAM
---------------------------

The left side is built from the program's syntax trees, never from the engine's results.
Prog has the constructors

  Constructor          Meaning (Prog.sem)
  -------------------  ------------------------------------------------------------------
  leaf e               the value of the expression e: a gate's kernel, a literal state, a
                       scalar or the identity
  app L a b            Σ_y a(o, y) b(y, x) over registers of levels L: U|s>, and A B
  ten k a b            a ⊗ b, a on the first k registers
  mul a b, add a b     product and sum
  inn L a b            Σ_y conj(a(y)) b(y): <a|b>
  cnj a                the complex conjugate
  loop L J lo cnt s i  s applied cnt times to i, iteration t reading J = lo + t
  sum D x b            Σ_{x<D} b: a sum of states over an index

A gate |x>... -> body becomes the kernel of its body: the output kets as deltas on the output
registers, the input registers read as the pattern variables. U^@n on a register of n
qudits, for a one-qudit kernel c ω_d^(α x y), is the digit-wise kernel c^n ω_d^(α ddot(x, y)).
A ket value reduced modulo its register's levels is read as a delta modulo those levels.
Each Lean definition carries the .ula line it translates as a comment.

5. INTEGER ATOMS
----------------

Ket values and phases may contain integer functions: digit products ddot and bitdot,
exclusive or, bits, digit sums, repunits (d^n - 1)/(d - 1), powers of two, the value of a
dimension, remainders modulo a dimension less one, the user's functions and powmod. Each is
an atom: a variable whose value is the
function of its arguments, each argument reduced modulo its register's levels, so that an
atom is periodic in every variable it reads. User functions and powmod are arbitrary
functions supplied by the valuation (V.fa); no axiom describes them. Exclusive or and bit 0
read modulo 2 are read as a sum and as the variable itself. A user function whose body is a
case split ifelse(y < L - 1, A, B), y reduced modulo the L levels of its register, is read as
A - [L ∣ y + 1] A + [L ∣ y + 1] B; a printed call f(x) of a function of one argument is read on
x modulo L.

For a loop variable j, d^j, floor(x/d^j) % d, x % d^j and floor(x/d^j) are the atoms power,
digit j, low j digits and remaining digits, d a dimension or an integer; j is an argument that
is not reduced (modulus 0), so that no elimination substitutes into it. Under an assumed
divisibility D1 ∣ D2 the quotient D2/D1 is an atom. An index of two levels that multiplies
another factor inside an exclusive or is read as itself modulo 2, so that the atom reads a bit.

6. THE PROOF
------------

Prog.sym translates the program into one symbolic sum with atoms; Prog.sym_ok proves it
denotes Prog.sem. The normaliser nfA (LCanon) is proved to keep the value of every term
(nfA_den); the certificate shows that the normal form of the difference between the program
and R is empty. The translation and each term's normal form are stated in the file (SYM,
NF) and checked by the Lean kernel (decide +kernel): the translation against the program,
the normal forms against the difference, and their merge against the empty list.

6.1 The normaliser of symbolic sums

Dimensions are monomials in dimension symbols, phases roots of unity times atoms ex g, scalars
constant expressions. The normaliser removes one bound variable per move:

  - a variable not used;
  - a variable pinned by a delta whose modulus divides its range;
  - a variable read only through roots of unity of its range, by the character sum
        sum_k omega_D^(k A + B) = D [D | A] omega_D^B;
  - a variable read only through one delta of its range, counted by gcd(a, D).

Canonicalisation substitutes each delta's pivot, merges roots of unity, those of two constant orders into one of their least common
multiple, moves the constant term
of a root of unity of constant order into the coefficient, writes each constant radical as a
square times distinct primes, evaluates constants and sorts factors.

6.2 Moves for integer atoms

Besides these moves, the normaliser
  - eliminates a variable an atom reads when a delta pins it and every argument reading it
    is reduced modulo a divisor of the delta's modulus, substituting into the arguments;
  - sums a variable x below N = d^n read only through digit products ddot(x, A_k) and
    linearly in roots of unity of order d (the digit-wise character sum
        Σ_{x<d^n} ω_d^(Σ_i x_i e_i) = Π_{i<n} d [d ∣ e_i]),
    leaving a digit condition, which it reads as a delta when it compares one value with a
    constant or two values;
  - removes digit products and digit conditions with a zero argument, merges atoms that
    compute the same value, reads a reduced argument mod(q, M) as q under a delta or root of
    unity whose modulus divides M, and drops unused atoms;
  - pins a variable to (-s c) mod D when a delta [D ∣ s x + c] of its own constant range fixes
    it, whatever else reads it;
  - pins a variable to a value read from atoms, the atoms that do not read the variable
    moved before those that do;
  - reads d^0 as 1 and the low 0 digits as 0, exclusive or with a zero argument as the other
    argument reduced, and a reduced argument mod(q, M) for a constant M with the coefficients
    of q reduced modulo M;
  - reads (a xor c(P - 1)) xor c P as a xor c(2P - 1) for a bit c = mod(q, 2) and a power of
    two P, every modulus a power of two;
  - reads an atom as an earlier atom computing the same value in the factors and in the later
    atoms;
  - inside a remainder modulo N - 1, reads a remainder modulo N - 1 as its argument, the
    value of N as 1, mod(-1, N) as 0 and, under a delta [N ∣ 1 + u] of the term, a reduced
    argument u = mod(y, N) as 0; reads mod(0, N) as 0;
  - reads a reduced argument mod(z, N) of a remainder z modulo N - 1 as z, and a delta
    [N ∣ 1 + z] or [N ∣ 1 + z - N] of such a remainder as false, for 2 ≤ N;
  - pins a variable x of constant range D to a reduced atom u = mod(q, D) by a delta
    [D ∣ s x + c u], s = ±1, D ∣ s + c;
  - under a delta [D ∣ s a + c b] equating two reduced atoms modulo a constant D, reads the atom
    of greater key as the other in the remaining factors;
  - orders the atom table canonically, each step the atom of least key among those that read
    no atom left, names the atoms by first occurrence in the factors and then in the table,
    renames bound variables by first occurrence and sorts the sums.
A loop is proved by induction on its count: the engine's invariant S(J) is shown to equal
the initial state at J = lo and to satisfy S(J + 1) = step_J(S(J)), both by the normaliser
with J free.

6.3 Rewriting under facts about free variables

Some identities hold only where a fact about a free variable holds. LPass rewrites atoms,
roots of unity and deltas under a context of such facts, each atom as a polynomial in new
atoms, and keeps the value of every term at each valuation where the context holds:

  d^(J+1) = d · d^J,  x mod d^(J+1) = x mod d^J + d^J · dig_J(x)      for J ≥ 0;
  d^v = N,  x mod d^v = x mod N                                    for N = d^(ν v);
  ω_{D1}^p = ω_{D2}^(q p),  [D2 ∣ q p] = [D1 ∣ p]                    for q = D2/D1, D1 ∣ D2.

The step of a loop whose range starts at lo ≥ 0 is checked with the invariant at J + 1
rewritten under J ≥ 0. A result is closed after the program's expression is rewritten under
its width links and divisibilities (section 3); where one normalisation leaves terms, their
normal form is rewritten and normalised once more. A delta [M ∣ s z + R] of a remainder
z = mod(u, N - 1), u = mod(y, N), is split into the three terms
[M ∣ s u + R] - [N ∣ u + 1] [M ∣ s u + R] + [N ∣ u + 1] [M ∣ R].

7. WHAT IS TRUSTED
------------------

The translation of a program's syntax into Prog (diracula.lean_lang) and of
the printed value into an expression, both shown in the file. The normaliser and the
meaning of Prog are proved in Lean. #print axioms of every certificate theorem lists only
propext, Classical.choice and Quot.sound; no certificate uses an axiom of the form
unproved_*. A result outside the certified fragment is reported as "cannot certify:
REASON" and never certified.

8. THE MIRROR
-------------

diracula.lean_lsym and the mirror functions of lean_lang follow the Lean
definitions on tuples. A certificate is written only when the mirror predicts that the
kernel's check succeeds; --check confirms it with Lean.

10. KNOWN GAPS
--------------

The following results are outside the certified fragment and are reported as "cannot
certify".

10.1 Values the program does not determine
Results that read rand, a branch on a value that is not concrete, or a state assigned from
Python have no syntax tree to translate. Every other result of the examples and benchmarks is
certified.
